本次产物只有本规范和文内两组候选样例。未生成完整 E3 数据文件，未实现或运行推理，未提取隐藏状态，未训练探针。候选样例是基于项目真实人物、机构和问题重新构造的 E3 教学材料，不是 E2 原文或模型实际输出。

## 1. 研究目标与已有证据

研究问题：在不一致的多来源证据中，模型能否区分已解决的更正与未解决的冲突？后续再研究相关信息的内部可解码性和因果作用。

- RQ1（本阶段）：控制记录标签、来源状态、顺序、机构绑定和表达方式后，作答能否随有效性关系正确变化？
- RQ2（未来）：相关区分是否能从隐藏状态中泛化解码？
- RQ3（未来）：针对性内部干预是否影响证据选择和最终回答？

当前只设计 RQ1，不将分类正确或成对作答正确当作 RQ2/RQ3 的证据，也不预先宣称四态设计具有论文新颖性。

已有结果来源：

- `results/e2_v2_pilot_report.md:24`：23 组 × 三条件共 69 条；充分 23/23、不足 23/23；冲突条件 0 条报告冲突、15 条选机构、8 条无法确定。
- `results/e2_v2_pilot_report.md:32`：同样 23 组的 v1 有 17 条报告冲突，v2 为 0 条；21 条冲突证据改写，2 条未改。
- `results/e21_conflict_adjudication.md:44`：23 条纳入、7 条暂缓，模型辅助审查，无独立人工一致性证据。
- `experiments/e2_run_inference.py:35`：E2 旧规则对“相互矛盾的信息”统一要求报告冲突，没有明确处理撤回、更正的优先关系。

E3 更换了任务定义和 Prompt，不能把新旧分数差直接称为模型能力提升。E2/E2.1 数据、脚本、原始回答和报告保留，E3 使用独立版本和路径。

## 2. 四类条件与标签层次

四类是并列的操作性场景，不是推理时间顺序，也不主张它们是四种互斥的天然属性。

| gold_evidence_state | 中文条件 | 准入定义 | expected_behavior | expected_answer |
|---|---|---|---|---|
| direct_sufficient | 直接充分 S1 | 有效证据唯一支持某机构；没有需要处理的撤回关系或未解决冲突 | answer_institution | 支持的完整机构名 |
| insufficient | 信息不足 I | 有效材料缺少所问关系，不能唯一确定机构；不得同时混入未解决冲突 | express_uncertainty | null |
| resolved_correction | 已解决更正 S2 | 两条记录就同一单值事实给出不同机构；权威状态说明明确撤回其中一条，并确认另一条为当前有效记录 | answer_institution | 当前有效记录对应机构 |
| unresolved_conflict | 未解决冲突 C | 两条当前有效、同等优先的记录，就同一单值事实给出互斥答案；没有足以消解的优先信息 | report_conflict | null |

另存 `gold_final_answerability`：S1/S2 为 `answerable`，I 为 `insufficient`，C 为 `unresolved_conflict`。因此 S2 在最终可回答性上仍属于充分。

S2 并非仅仅“第二句带并非/而是”；必须有明确、可解释的撤回和生效关系。C 不是“两所机构名字不同”；必须排除多事件、兼任、联合归属等自然同真解释。

“记录 A 如此记载”和“记录 B 如此记载”可以同时为真。C 的冲突定义针对两份当前有效记录所承载、需要用于回答的事实内容，而非声称两份文件不可能同时存在。

“主管部门核验”是受控任务中给定的来源设定，不是对虚构人物执行了现实核验。结论限于模型能否遵循这一明示关系。

## 3. 样本准入、排除和人工审核

### 3.1 基础问题

候选来源为 E2.1 纳入的 23 组；它们全部是开发材料，不是未接触测试集。23 组清单以裁决记录为准。原来的 7 组暂缓项不自动重新纳入。

每组四条件必须重新审查，不能继承 E2 标签作为通过凭据：

1. 固定同组问题、人物、两机构和目标关系。名称不依赖现实知识解释。
2. 明确同一事件、时间范围、角色和机构归属；单值性必须在文本或明确的任务设定中成立。
3. 发现联合培养、多学位、多次任职、兼任、代聘、出版方/印刷方等自然兼容解释时，重写候选或排除；重写必须标明新的设定，不能冒充原样本事实。
4. 单值范围声明四条件共用，不能只给冲突条件加“唯一”。不得自行提供目标机构。
5. I 条件不提供目标关系的肯定、否定或可间接推出答案的材料；两机构都可以出现，不能把机构缺席当作唯一区别。
6. S1 的有效证据没有未解决冲突。撤回记录不能在状态说明中又被称为当前有效。
7. S2/C 使用完全相同的两条记录正文、范围声明、问题与记录身份；仅改变状态说明。
8. 来源状态说明在任务中优先于记录正文，且自身无争议。不得把两条原始记录的矛盾扩大成对所有任务规则的不信任。
9. 不为凑齐 23 组而放行；以实际通过审核的 N 计算规模。若某组无法形成核心配对，应整组退出核心比较。

### 3.2 审核记录

`review_status` 为 `pending_human_review`、`approved` 或 `excluded`。每组保存审核者类型、日期、具体理由、可能同真情景与处置。模型辅助审查不标为人工审核。

审核者在看目标 Qwen 输出之前裁决标签。至少一名真实人工审核者确认后才可称为“人工审核通过”；没有独立双人标注时不报告标注者一致性。若之后补独立审核，另记盲审和分歧裁决。

审核覆盖 A/B 有效性互换、记录顺序互换、机构绑定互换和否定范围。局部改字导致状态不完整或歧义，不得强行保留。

本规范的两组候选目前均为 `pending_human_review`，不算已完成审核。

## 4. 因素组合与规模

### 4.1 核心块：每组 8 条输入

| 场景 | 有效性 | 记录呈现顺序 | 每组条数 |
|---|---|---|---:|
| S1 | 两条相容记录有效，其中一条支持答案 | 基础顺序 | 1 |
| I | 两条相容记录有效，但均不提供所问关系 | 基础顺序 | 1 |
| S2 | A 有效/B 撤回，或 A 撤回/B 有效 | A→B、B→A 均覆盖 | 4 |
| C | A/B 均有效、同等优先、未裁定 | A→B、B→A 均覆盖 | 2 |
| 合计 | | | 8 |

顺序互换只移动完整记录块，不交换 A/B 身份、机构绑定或状态含义。状态说明放在两条记录之后，核心块保持其位置不变。记录标签不表示时间先后、可信度或优先级。

S2 的两种有效性用词汇相同、归属互换的模板，不能固定 B 为正确来源：

- A 有效：`主管部门核验状态：档案 A 当前有效且未被撤销；档案 B 已正式撤销。现仅采信档案 A。`
- B 有效：`主管部门核验状态：档案 A 已正式撤销；档案 B 当前有效且未被撤销。现仅采信档案 B。`
- C：`主管部门核验状态：档案 A、档案 B 均为当前有效记录，优先级相同；尚未作出确定采信哪份记录的裁决。`
- S1/I：`主管部门核验状态：档案 A、档案 B 均为当前有效记录，优先级相同。`

以上为候选 T1 模板；不能因文本写进规范就称已审核通过。状态说明不直接包含正确机构名，也不出现“这是修正/这是冲突”的分类答案。

若 N=23，核心块为 184 条输入。每条独立执行作答和分类两种任务，为 368 次样本级推理，不等于 368 个独立基础问题。

### 4.2 补充控制：冻结前单独登记

- 机构绑定 M0/M1：同组两机构与 A/B 的绑定互换，同时保持所有条件的映射一致。范围声明和问题不变。S1 的支持答案也随其正文正确变化。
- 否定范围：使用“已撤销/未撤销”或“被撤回/仍有效”的匹配模板，检查否定作用于哪份记录。仅说“未撤销”不足以证明有效；必须明确当前有效。
- 等价模板：在不改变有效性含义的前提下，更换状态表述；在冻结清单中明确模板 ID。不能靠较大版本号或较晚日期自动推断有效性，除非给出通用优先规则。
- 标签表述：后续可使用等价中性标签替代 A/B，防止档案字母特征；不与其他因素同时无记录地改变。
- 反例：在 C 中出现“尚无更正/未撤销”等措辞，在 S1 中出现“已核验”但无撤回过程，避免特定词只属于某类。

不能把“使用撤销/有效等任务相关词”直接判作捷径。诊断目标是跨归属、否定、顺序和模板的组合泛化。

核心块并未全交叉机构绑定、模板或状态说明顺序；184 不能宣称已排除所有这些偏差。推荐先在两组审核样例上检查完整 M0/M1 映射，再冻结补充子集或完整交叉清单，不凭运行成绩挑选。

若对核心块整体增加 M0/M1 全交叉，每组 16 条、N=23 时 368 条输入；两任务为 736 次推理。这是规模备选，不是本次执行授权。其他控制的数量也必须写入冻结清单，不能计入原 184 后不更新分母。

## 5. 两套独立 Prompt（候选 v0.1）

两任务使用同一 `evidence_text`，分别启动独立上下文。分类输出、理由或标签不得提供给作答任务。四条件共用各自的统一模板，模型不接收 gold 字段、审核理由、文件名或 condition。

### 5.1 任务作答模板

这是一项受规则约束的作答测试，不称为完全自由的自然生成。

```text
请仅根据以下资料回答问题，不使用资料以外的知识。

判读规则：
- 档案标签不代表时间先后或可信度。来源状态说明规定哪些记录当前有效；它优先于记录正文。
- 已正式撤销的记录不再作为当前答案依据。不得仅凭记录的呈现顺序认定更正或优先关系。
- 结合当前有效的记录与范围说明，若能唯一确定答案，只输出机构完整名称。
- 若当前有效的记录就同一事实给出不能同时成立的结论，且没有可靠的优先关系，只输出“证据冲突”。
- 若没有上述未解决冲突，但资料不足以唯一确定答案，只输出“无法确定”。
不要输出理由或其他内容。

资料：
{evidence_text}

问题：{question}
```

规则固定后四条件一视同仁。显式提供有效性处理规则限制了结论范围：测量的是给定规则下的处理能力，不是无提示的自发策略。将来测试旧 Prompt 或不列规则的 Prompt，应作为独立因素和版本。

### 5.2 显式状态分类模板

```text
请仅根据以下资料判断证据场景，不回答问题中的机构。
档案标签不代表时间先后或可信度。来源状态说明优先于记录正文；已撤销的记录不作为当前答案依据。

分类定义：
- direct_sufficient：有效证据直接支持唯一答案，无需处理撤回更正，也没有未解决冲突。
- insufficient：有效资料缺少回答所需信息，且不存在未解决冲突。
- resolved_correction：记录间存在不一致，但已有明确撤回与生效关系；依据当前有效记录可以回答。
- unresolved_conflict：当前有效记录对同一事实互相排斥，且没有足以决定采信对象的优先关系。

资料：
{evidence_text}

问题：{question}

只输出上述一个英文类别，不输出其他内容。
```

分类标签本来就是此任务必须呈现的选项，不把它称为标签泄漏；真实 gold 值仍不输入。核心版固定标签顺序，不声称已排除类别列表位置偏好。类别顺序平衡可另作补充因素。

## 6. 数据与记录字段规范

将来使用独立 `e3_` 前缀，不覆盖历史。下面是字段约定，不是当前已生成的数据：

| 字段 | 含义或约束 |
|---|---|
| schema_version / dataset_version | 字段格式版本、冻结的数据版本 |
| item_id | 唯一编号，包含组、条件、有效性、顺序、绑定、模板等变体标识 |
| base_group_id / pair_id | 基础问题与配对单元；所有衍生版本绑定到同一基础问题 |
| source_reference | 原始文件、group_id、question/person/institutions 来源及 hash |
| split / development_history | 开发/验证/测试及是否参与过改写、审核 |
| person / question / target_relation | 人物、问题、目标关系 |
| institution_x / institution_y | 中性的实体身份，不能将 x 永久解释为金标 |
| event_scope / single_value_basis | 同一事件、时间和单值范围；新增设定明确标注 |
| records | 各记录 ID、正文及所含机构，不按显示位置重命名 |
| document_order / institution_binding | 记录显示顺序及 A/B 与 x/y 的绑定 |
| source_status_text / status_template_id | 模型可见状态说明及表述版本 |
| source_validity | 程序标注的 A/B 当前有效/已撤回状态，须与可见文本一致 |
| evidence_text | 实际提供给两任务的完整资料，包含范围声明、记录和状态说明 |
| gold_evidence_state | 四类场景之一，仅标注与评分使用 |
| gold_final_answerability | answerable / insufficient / unresolved_conflict |
| expected_behavior | answer_institution / express_uncertainty / report_conflict |
| expected_answer | S1/S2 为完整机构名；I/C 为 JSON null，不填虚假的机构金标 |
| expected_output | 当前作答模板要求的准确输出文字，I 为无法确定、C 为证据冲突 |
| expected_valid_record_id | S2 为 A 或 B；S1 按实际支持记录；I/C 为 null |
| review_status / review_history | 审核状态、审核者类型、理由、分歧及裁决 |

当前模型只应收到统一 Prompt、`evidence_text` 与 `question`，不直接收到机器标注的状态字段。相同输入可在两任务间复用，但推理记录分别保存 `task_type`、完整消息、chat template 后 prompt 或其摘要、answer_raw、token 数、截断标志。

记录模型及 tokenizer 来源、配置摘要、库版本、dtype、解码参数、seed、批次、实际执行脚本和 Prompt/数据 hash。仅有路径不等于验证权重完全相同；若未来跨运行比较，登记权重来源与足以识别版本的摘要。

### 7.1 G01：博士学位授予学校

此范围为新构造的受控设定，不宣称是 E2 原样本已有事实。

| 条件 | 档案 A | 档案 B |

### 7.2 G03：本科学业完成院校

来源：`data/e2_craft_input.json:43` 的 G03 条目；真实基础问题为“陆望澜在哪所大学完成本科学业？”，人物陆望澜，机构岑川大学/沐棠大学。

## 8. 评分：语义、格式和任务分开

### 8.1 作答行为

始终保留 `answer_raw`，不在生成时强制选择预定义答案集合。评分分别保存：

- `behavior`：answer_institution、express_uncertainty、report_conflict、mixed、other、pending_review。
- `selected_institution`、`selected_record_id`、`selected_position`：根据该条绑定和呈现顺序推导，不把 A/B 与第一/第二位置混用。
- `semantic_correct`：行为及所选机构是否符合标签。
- `format_compliant`：是否遵守只输出完整机构名或约定短语。
- `truncated`、`review_status`、`review_note`：流程和复核信息。

S1/S2 必须回答各自 `expected_answer`；S2 选择已撤回记录对应机构判为错误。I 的无法确定是期望行为。C 的无法确定记为“谨慎未选边”，不计为明确报告冲突，也不与选机构合并。

否定、混合和解释性回答转语义复核：“没有冲突”不能因含冲突二字判为 report_conflict；同时报告冲突又坚持唯一机构，不自动判为完全正确。核心词命中只作初筛，不能把机构子串命中当作完整名称匹配。

最小自动规范化只允许 Unicode/首尾空白等预先登记的等价处理。语义正确但带解释可记 semantic_correct=true、format_compliant=false；无法稳定判断则 pending_review，不强行评分。

未决样本保留在总分母，主结果同时列正确、错误、待审。必要时给正确率上下界：已确认正确/n 到（已确认正确+待审）/n，不只报告剔除待审后的高分。

### 8.2 分类行为

分类 gold 为 `gold_evidence_state`；记录预测标签、四类混淆矩阵、每类召回与总准确率。格式错误单列；语义可识别但格式不符分别记录，不能静默删样本。

分类与作答分别完成后才按 item_id 关联。“分类正确、作答选边”是不同 Prompt 下的行为差异，不是同次生成知道但不用，更不是 Probe 结果。

### 8.3 核心指标与固定分母

| 指标 | 定义 |
|---|---|
| S1 正确率 | S1 中给出支持机构的数量 / S1 总数 |
| I 恰当拒答率 | I 中表达无法确定的数量 / I 总数 |
| S2 有效更正采用率 | S2 中给出当前有效机构的数量 / S2 总数 |
| C 冲突报告率 | C 中明确报告冲突的数量 / C 总数 |
| C 选边率 | C 中给出任一单独机构的数量 / C 总数；A/B、x/y、前/后位置分别列 |
| C 谨慎未选边率 | C 中仅表达无法确定的数量 / C 总数 |
| 顺序一致率 | 同组同状态同绑定，AB/BA 两次语义行为及机构选择一致的对数 / 全部完整顺序对数 |
| 顺序成对正确率 | AB/BA 两次均正确的对数 / 全部完整顺序对数；与一致率并列，避免两次都错也算好 |
| 有效性翻转成对正确率 | 固定顺序/绑定/模板，A有效与B有效两次均采用正确机构的对数 / 全部此类完整对数 |
| 修正—冲突成对正确率 | 固定组/绑定/模板/顺序，对每个S2有效性变体与对应C配对，两次均正确的对数 / 全部此类完整对数 |
| 组级严格通过率 | 同组全部核心S2/C变体均正确的组数 / 纳入组数 |

核心块每组：顺序对 3 对（S2_A、S2_B、C），有效性翻转对 2 对（两种顺序），修正—冲突对 4 对（两种有效性×两种顺序）。同一个C用于两次配对，不能视为独立重复实验。顺序指标不覆盖核心块中只有单一顺序的S1/I。

先报计数和分母，后报比例；语义正确和严格格式达成分别汇报。按基础问题 group_id 聚类重采样估计区间，不能将衍生版本当作独立样本。仅两个审核样例不做总体置信推断。
